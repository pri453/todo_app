# To-Do App

A simple task manager built with React and Vite.

**Live demo:** https://todo-app-trlf.vercel.app/

![To-Do App screenshot](screenshot.png)

## Features

- Add tasks with the Add button or the Enter key
- Edit a task in place (Enter to save, Escape to cancel)
- Delete tasks
- Mark tasks as complete with a checkbox
- Filter tasks: All, Active, Completed
- Shows how many tasks are left
- Tasks are saved in the browser (localStorage), so they stay after a refresh
- Empty tasks are not added

## Tech Stack

- React (Hooks: `useState`, `useEffect`)
- Vite
- CSS
- localStorage

## Run Locally

```bash
git clone https://github.com/pri453/todo_app.git
cd todo_app
npm install
npm run dev
```

Then open the local address shown in the terminal.
